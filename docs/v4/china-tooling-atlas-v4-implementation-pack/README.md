# China Tooling Talent Atlas - V4 Implementation Pack

This pack turns the current site from a careful evidence viewer into a client-facing monitoring product.

The goal for this sprint is not to add more data. The goal is to make the current data useful. The site should answer one question clearly:

> What should a serious observer watch to know whether China is converting semiconductor-equipment R&D into production-ready tooling capacity?

## Recommended direction

Public title:

> China Chip Tooling Talent Monitor

Project name can remain:

> China Semiconductor Tooling Talent Atlas

The word "monitor" is more useful for DGA, McKinsey, Bloomberg, and corporate readers. "Atlas" suggests completeness and geography. The current product is stronger as a public-record monitor and evidence brief.

## One-week outcome

Ship a V4 beta with:

1. Cleaner homepage copy with fewer disclaimers.
2. Firm dossiers for AMEC, NAURA, and ACM Research Shanghai.
3. A recognizable schematic mainland China map.
4. Click-through from homepage cards into firm pages, segment pages, and filtered explorer views.
5. A short "How to use this as a monitor" section for corporate, policy, and research readers.
6. A less AI-sounding language layer.
7. A boss demo path and portfolio pitch.

## Rule for the week

Do not expand the dataset. Do not add a database. Do not add a map library. Do not create composite scores. Do not add new sectors.

Make the current product more intelligible, more clickable, and more analyst-owned.
