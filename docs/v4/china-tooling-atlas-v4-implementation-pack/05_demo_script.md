# Demo script for DGA / employer conversations

## 30-second version

```text
I built a beta evidence product on China’s semiconductor-equipment talent system. Most analysis tracks export controls, product announcements, and market share. I wanted to track the people and organizations behind tool catch-up: R&D teams, service capacity, role families, city clusters, shortage lists, and firm disclosures. The result is a public-record monitor with a source ledger, firm dossiers, segment briefs, and an explorer.
```

## 2-minute walkthrough

1. Start on the homepage.

```text
The product starts from one question: what should an analyst watch to know whether Chinese toolmakers are converting R&D into production support?
```

2. Point to the findings.

```text
The first finding is a source discipline point: 38 percent of rows are structural scaffolding, not field evidence. I keep that visible because broad STEM and discipline counts are easy to overread.
```

3. Open AMEC or NAURA.

```text
This is the next-click layer. If a user sees AMEC, they can open a firm dossier rather than falling into a raw table. The dossier explains what the firm does, which tool segments it touches, what workforce categories it discloses, what to watch, and what not to infer.
```

4. Open a segment page.

```text
The segment pages translate technical bottlenecks into role families. Etch is not deposition; metrology is not lithography. Each segment needs different combinations of plasma, chemistry, optics, algorithms, calibration, service, and applications engineering.
```

5. Open the map.

```text
The map is not a talent ranking. It shows where public records concentrate and where an analyst might start checking city-level sources.
```

6. Open the explorer and methodology.

```text
The explorer keeps the work auditable. Every row traces back to a source. The methodology keeps the claims bounded: public visibility, not capability.
```

## What this shows about you

```text
This project shows I can scope a messy strategic-technology problem, build a defensible evidence model, create an interactive product, and translate technical details into client-facing analysis.
```

## For DGA specifically

```text
This could become a reusable framework for monitoring China critical-tech bottlenecks beyond chip tooling: advanced packaging, data-center power and thermal systems, critical minerals processing, and other areas where public records reveal partial but useful signals.
```
