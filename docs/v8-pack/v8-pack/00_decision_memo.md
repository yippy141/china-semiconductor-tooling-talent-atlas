# V8 Decision Memo

## Product decision

V8 should not add more firms or more rows. It should add interpretation.

The current site presents source-backed facts, but it often stops before answering what those facts mean. A reader can see AMEC R&D personnel, NAURA R&D scale, ACM after-sales staff, and Piotech deposition focus, but the site does not consistently translate those facts into implications.

## New product promise

A public-source briefing tool for understanding whether Chinese semiconductor-equipment firms are building the R&D, applications, service, calibration, and training organizations needed to move from product announcements to supported fab deployment.

## Main change

Add an interpretation layer:
- What this number means.
- What would change the assessment.
- What the site can infer.
- What it cannot infer.

## Map decision

The current map should be reframed as source coverage. It should not imply talent supply, workforce size, or capability density. A talent geography map needs supply, demand, and absorption layers. That is V8.5 or V9.

## Supply page decision

Add a second-click /supply page now as a scaffold. It should explain which disciplines and institutions plausibly feed tooling roles. It should not claim exact discipline-specific PhD counts unless a later Deep Research pass supports those counts.

## Article decision

Publish the narrative essay on Substack. Keep the website as the interactive companion. The website should be useful without the essay, but the essay will carry voice, argument, and wider geopolitical context.
