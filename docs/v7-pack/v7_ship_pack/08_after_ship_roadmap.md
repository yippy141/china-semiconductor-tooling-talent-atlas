# 08 — After-ship roadmap

## V7.1 — Verification pass

Verify the top 30 homepage and dossier claims.

Add fields where useful:

- verification_status
- source_page
- source_excerpt
- review_notes

Do not verify all rows at once. Verify what public readers see first.

## V7.2 — Job-posting pilot

Run one limited job-posting pass for two segments:

- etch/clean/strip;
- deposition.

Track role titles such as process engineer, field application engineer, service engineer, RF engineer, deposition process engineer, vacuum engineer, and clean-process engineer.

Do not make job postings a headcount measure. Treat them as demand signals.

## V8 — Talent pipeline article

Create a separate article:

> The upstream pipeline: which Chinese disciplines feed chip tooling?

This should use official MOE discipline categories, selected university programs, and a discipline-to-segment matrix. Do not claim exact plasma-physics PhD output unless sourced.

Possible exhibits:

- discipline-to-segment flow;
- official MOE discipline crosswalk;
- institution cluster table;
- what official education data can and cannot show.

## V9 — Comparator module

Add hard-number Western comparators only after source-checking.

The safe first version is qualitative:

- Lam / AMEC for etch and customer support logic;
- Applied Materials / TEL / NAURA / Piotech for deposition and broad WFE portfolios;
- KLA / Jingce / BEIM / Skyverse for metrology and inspection;
- ASML / SMEE for lithography sidebar.

Do not turn this into a scoreboard.

## V10 — Cinematic command map

A restrained supply-chain command map can become a memorable landing surface later.

Build it only after the brief has shipped and the purpose is clear.

The command map should show:

Universities -> role families -> toolmakers -> product families -> fabs -> support functions -> public records.

It should be progressive enhancement, disabled for reduced motion, and never replace the article.
