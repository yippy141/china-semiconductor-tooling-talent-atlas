# 07 — Demo script

## 30-second version

I built a public-source monitor for China's semiconductor-equipment workforce. The question is not whether Chinese firms can announce tools. The question is whether they are building the staff and support systems that make tools work in customer fabs: R&D teams, field engineers, service staff, calibration routines, training systems, and repeat deployment.

The front page gives the brief. Firm dossiers show what AMEC, NAURA, ACM Research Shanghai, Piotech, and others disclose. The explorer and source ledger keep the claims auditable.

## 2-minute version

Start on the homepage.

Say:

This began as a China STEM talent map. That was too broad. I narrowed it to semiconductor manufacturing equipment because it is strategically important, commercially relevant, and technically specific.

The key point is that broad STEM counts are the wrong denominator. Etch tools need plasma, RF hardware, surface chemistry, and fab-ramp knowledge. Deposition needs thin-film chemistry, vacuum behavior, chamber stability, and process integration. Metrology needs optics, algorithms, calibration, and customer-site tuning.

Scroll to the firm exhibit.

Say:

The best public workforce window is not official education data. It is listed-company filings. These show R&D staff, technical staff, after-sales categories, degree mix, and product families. They do not prove capability, but they show how firms are organizing around equipment.

Open a firm dossier.

Say:

A user can click into AMEC or Piotech and see what the firm makes, which segment it touches, what workforce signal is visible, what would change the assessment, and which source rows back the claim.

Open methodology or explorer.

Say:

The data layer is intentionally conservative. It separates direct public records, proxies, and taxonomy scaffolding. It does not produce a score or ranking.

Close:

The value is not that this predicts Chinese tool capability. The value is that it gives analysts a repeatable way to monitor the public records that would matter if Chinese tools move from product claims toward production support.

## 7-minute version

Use this order:

1. Homepage title and standfirst.
2. Anchor-firm exhibit.
3. Argument section.
4. Discipline-to-segment matrix.
5. Firm workforce chart.
6. Piotech dossier.
7. Explorer filtered by Piotech or deposition.
8. Methodology.

Finish with:

The framework can extend later to advanced packaging, data-center power and thermal systems, critical minerals processing, or other China critical-tech bottlenecks. But the method stays the same: define the technical bottleneck, map the role families, collect public records, separate evidence from inference, and make the source trail inspectable.
