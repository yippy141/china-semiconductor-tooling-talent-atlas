01   The pack

Eight files. Two read paths.

How to use

The PM reads files 00 → 01 → 02 and answers ten open questions at the foot of 01. The coder reads 02 → 03 → 05 for reference, then runs the prompts in 04 one at a time. Reviewer signs off against 06 after each prompt.

Files are plain markdown. Drop the folder into the repo's docs/ directory and open them in VS Code panels alongside the prompts you're running.

06   For the PM

Ten questions to answer before the coder runs.

Why

Each question has a sensible default. Confirming or overriding now prevents an awkward re-roll later. Full reasoning for each lives in 01_pm_decision_brief.md.

  1. Track choice

    L, M, or F? Picks how many prompts the coder runs.

    DefaultM
  2. Typeface flavor

    Serif throughout (Economist register) or serif headlines + sans body (FT/Bloomberg register)?

    DefaultSerif throughout
  3. Accent

    Single editorial amber on §-glyphs and drop caps, or pure monochrome?

    DefaultAmber
  4. Anchor-firms exhibit format

    Bare list of four firms with one figure each, or tiny bar visualization? Bars risk implying cross-firm comparison the denominators don't support.

    DefaultBare list
  5. What happens to the Core question pull-out

    Drop, move next to ComparatorFrame, or move to the brief head?

    DefaultMove to brief
  6. Issue number

    Use Issue 04 or just Beta · May 2026? The dataset is versioned by manifest.json.

    DefaultBeta + date
  7. Masthead nav items

    Which four (or five) routes appear in the top nav on every page?

    DefaultBrief · Firms · Segments · Explorer · Methodology
  8. What to call the home

    Used in masthead and HTML <title> tag.

    DefaultTooling Talent Atlas
  9. Body lede language

    Lift the first paragraph of /essay verbatim, or write a fresh summary for the home? Verbatim = single source of truth, no drift.

    DefaultLift verbatim
  10. Scope creep

    Should this pack also rework the toolmaker footprint grid, add print.css, or apply v7 to dossier pages? Flagged as next-steps, not in scope today.

    DefaultHome only
07   Honored

Constraints from AGENTS.md.

Editorial

Never invent data. Every number, name and ID rendered by v7 is read from an existing file under data/editorial/ or lib/.

No score, ranking, or composite index. The forbidden-string list in §6 of the copy bank guards against this.

Public-source signal language. "Public evidence signal," "evidence strength," denominators visible — preserved.

Mainland PRC only. No new geographic claims.

Technical

Next.js App Router + TypeScript + Tailwind v4. v7 uses the CSS-first @theme inline block already in use. No tailwind.config.ts introduced.

No new dependencies. next/font/google is bundled with Next 16.

Local CSV + generated JSON. No DB, no auth, no scraping. Untouched.

Smallest coherent diff. Each prompt in 04 touches between 1 and 5 files; total v7 surface area is < 12 files.

The product is doing the difficult half right: it has refused to invent a league table and built a record of denominators instead. The home page just hasn't caught up to the seriousness of the work behind it. v7 is the smallest set of changes that closes that gap. Summary
