# 05 Claude Design Token Plan

Use Claude Design after the article-first structure exists. Do not upload the full repo.

## Use cases

Use Claude Design for:

1. Homepage first two scrolls
2. Firm dossier page layout
3. City map visual treatment

Do not use it for:

- data claims
- source verification
- code edits
- large repo-wide redesign

## Upload only these assets

For each run, upload:

- Screenshot of the homepage hero and first two sections
- Screenshot of firm workforce chart
- Screenshot of city map
- Screenshot of one firm dossier page
- Optional: one DGA report page screenshot that shows the desired briefing rhythm

## Prompt

```text
You are reviewing a serious public-source brief for corporate strategy, policy, and data journalism readers.

Product:
Can China Staff Its Chip-Tooling Push?

Audience:
Semiconductor equipment firms, policy advisors, consultants, Bloomberg/Economist-style readers, and think-tank researchers.

Goal:
Make the first two scrolls feel like an analytical brief, not a dashboard or SaaS landing page.

Constraints:
- Do not invent data.
- Do not add rankings or scores.
- Do not make the product look like a game UI.
- Keep caveats in notes, not in headlines.
- Keep the site serious, readable, and source-led.

Please give:
1. A critique of hierarchy.
2. A stronger layout for the first two scrolls.
3. Tailwind-level style guidance.
4. What to remove.
5. What not to change.
```

## Implementation rule

Do not ask Claude Design to implement. Take the design advice and use Claude Code or Codex with one small prompt at a time.
