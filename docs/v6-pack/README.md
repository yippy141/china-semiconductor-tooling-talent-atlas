# V6 Executive Brief Implementation Pack

Project: China Semiconductor Tooling Talent Atlas

Goal: turn V5 from a good evidence system into a client-facing brief and monitor that a DGA-ASG colleague, corporate strategy reader, or policy analyst can understand in under one minute.

Core decision: the product is not a database tour. It is a public-source monitor for whether Chinese semiconductor-equipment firms are building the staff and support functions needed to move tools from product claims into customer fabs.

Use this pack in order:

1. Read `00_take_stock_and_decision.md`.
2. Run the 48-hour sprint in `01_two_day_sprint.md` before showing friends and advisors.
3. Run the one-week ship plan in `02_one_week_ship_plan.md`.
4. Use `03_copy_bank.md` for replacement language.
5. Use `04_claude_code_prompts.md` one phase at a time.
6. Use `05_claude_design_token_plan.md` only after the new page order exists.
7. Use `06_research_plan_phd_module.md` only after the public brief is stable.
8. Use `07_demo_script_and_feedback.md` for advisor and boss demos.
9. Use `checklists/final_ship_checklist.md` before deploy.

Non-negotiables:

- No new sectors in this release.
- No capability scores.
- No real-time claims.
- No individual-level talent mapping.
- No broad PhD module on the homepage unless the data are source-checked.
- Caveats belong in chart notes and methodology, not in headlines.
